# Video Editing Outsourcing Benchmarks from 7,056 Orders

Aggregate benchmarks from 7,056 outsourced video editing orders placed with Mark Studios between January 2023 and September 2026: delivery windows, the mix of services ordered, raw footage lengths, repeat clients and seasonality. Aggregates only; no client, order or editor identifiers, and no cell built from fewer than ten orders.

Published by [Mark Studios](https://www.markstudios.com) with the full write-up, method and limitations at **https://www.markstudios.com/research/video-editing-outsourcing-benchmarks**.

## Files

benchmarks.csv: one row per published figure (table, row, value, unit, n). sources.csv: the evidence table behind the page, one row per figure with its method notes.

Files in `data/` are copied from the live page on 2026-10-25; the page is the source of truth and is re-verified quarterly.
